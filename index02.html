Guide

이용안내

작업 및 이용 안내

  • 작업 범위 Warudo API 세팅, 커스텀 API 개발, 간단한 3D 모델 제작을 진행합니다.
    • Warudo API 설치 및 커스텀 트리거 제작
    • 3D 모델 제작 및 Warudo 연동
    • Warudo PRO / 일반 버전 모두 작업
  • 세팅 방식 작업 난이도와 숙련도에 따라 아래 두 가지 방식으로 진행합니다. 세팅 방식에 따른 추가금은 발생하지 않습니다.
    • 원격 세팅 (초보자) — RustDesk로 직접 세팅해 드립니다.
    • 파일 전달 (숙련자) — 설정 파일만 전달해 드리며, 안내에 따라 직접 적용하시는 방식입니다.
  • RustDesk 설치 (원격 세팅용) 원격 세팅 전, 아래 순서대로 RustDesk를 설치해 주세요.
    1. RustDesk 다운로드 페이지 접속
    2. Windows 항목에서 x86-64 (64-bit) 의 EXE 클릭해 다운로드
    3. 다운로드한 실행 파일 더블클릭 (설치 없이 바로 실행되는 방식이라 별도 설치 과정이 없습니다)
    4. 실행하면 화면에 표시되는 본인 ID와 임시 비밀번호 확인
    5. 비밀번호는 프로그램을 켤 때마다 새로 생성됩니다. 세팅 직전에 다시 확인해 주세요.고정 비밀번호로 쓰고 싶다면 설정(톱니바퀴) → 보안 탭에서 직접 설정할 수도 있습니다.
    6. Discord(@im_rabbi)로 ID와 비밀번호를 보내 주시면 원격 세팅을 진행합니다
    7. 원격 접속 중에는 RustDesk 창을 닫지 말고 그대로 켜 두세요

    ※ RustDesk는 설치 없이 실행 파일만으로 바로 사용할 수 있어 별도 계정 로그인이 필요 없습니다. 백신 프로그램에서 처음 실행 시 경고가 뜰 수 있는데, 이 경우 허용해 주시면 됩니다.

  • 작업물 활용 안내 완성된 작업물은 포트폴리오, SNS, 홍보 자료 등에 일부 또는 전체가 활용될 수 있습니다.
    • 비공개를 원하시는 경우 주문 전 미리 말씀해 주세요.
